# 天题_本来样貌

> 天题 = 信息的本来样貌。不是"规律层提问", 是信息在被解释前的原始呈现。

## 提取协议

### 提取问题
1. 信息在被解释前实际呈现什么结构?
2. 有什么状态和痕迹?
3. 有什么可见规律(原始的, 未被理论框架解释的)?
4. 什么是未知的/待解的?

### 输出格式

```yaml
tianti:
  original_form: <信息在被解释前实际呈现的结构/状态/痕迹>
  observed_structure: <可见规律>
  unknowns:
    - <未知/待解部分>
```

### 示例

对象: 唐三彩钴蓝釉陶俑(藏节点)

```yaml
tianti:
  original_form: 陶胎上覆蓝色彩釉, 釉色呈深蓝带紫调, 胎质疏松有气孔
  observed_structure: 钴蓝呈色不均匀, 釉面有流淌痕, 胎釉结合处有过渡层
  unknowns:
    - 钴矿具体产地(波斯?还是其他?)
    - 钴料配方比例
    - 烧成温度精确值
```

### 边界

天题只记录信息的本来样貌, 不记录:
- 规律本身(属于天才, 在藏节点中)
- 读取方式(属于地题)
- 读取者的解释(属于人题)
- 抽象规律(属于归的abstraction层)
