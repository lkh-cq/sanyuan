# 元-互双观测空间归一化架构 (v3.2.0)

> v3.2.0核心理论推进: 从单空间SVD归一化迁移到元信息-互信息双观测空间独立归一化。
> 本文件是session中与对窗(deepseek)讨论形成的理论结晶的 condensed reference。

## 问题诊断: 旧SVD归一化的三个缺陷

1. **数学缺陷**: rank=2时 σ₃=0 导致 κ=σ₁/σ₃ 除零, G3=0, 无法评估秩为2的信息质量
2. **架构缺陷**: 单空间阈值逻辑未区分元信息(静态属性)与互信息(动态关系), 用同一套阈值评估两类不同信息
3. **功能缺陷**: 无跨空间一致性检查, 无法识别元信息与互信息之间的冲突, SVD优化全局方差解释而非任务功能保持

## 双观测空间定义

### 元信息空间 M
- 对应信息的固有属性编码
- 映射三才层: 天才(规律)/地才(环境)/人才(实践)
- 记录静态属性, 无时间维度依赖
- 三才藏为主编码器
- 独立归一化输出: M_T (元信息任务视图)

### 互信息空间 H
- 对应信息之间的全部关系状态编码
- 互记录: 直接互/复合互/路径残差/流止互(FlowEvent)/转换互/反馈互/条件互/时序互
- 记录动态关系, 可带时间戳
- 互/SKILL.md 为主模块
- 独立归一化输出: H_T (互信息任务视图)

### 互 ≠ FlowEvent (v3.2.0关键修正)
- v3.1.0: 互=FlowEvent运行状态 (过窄)
- v3.2.0: 互=独立关系观测空间, FlowEvent⊂互
- FlowEvent只是互空间中记录天地人拓扑流止事件的子类型
- 互还包括不依赖天地人拓扑的关系(如文献间引用关系)

### via_role约束
- FlowEvent子类型: via_role=di 强制(地居中)
- 一般MutualNode: via_role不受此约束

## 任务边界 B_T

在任何过滤之前编译:
```
B_T = {
  task_goal, F_T(可验证功能测试),
  forbidden_loss(禁止损失),
  epsilon_T(误差预算, 科研0.05/快速0.2),
  required_spaces(至少meta+hu),
  optional_spaces,
  meta_axes, hu_axes
}
```

路由门: required_spaces只有meta+hu且epsilon_T≥0.2 -> 快速配方; 否则 -> 科研配方

## 7步归一化流程

1. 任务边界编译 -> B_T
2. 选择观测空间
3. 元信息空间独立归一化 -> M_T (三才轴提取, 任务条件压缩 D_f≤ε_T)
4. 互信息空间独立归一化 -> H_T (关系提取, 路径残差保护)
5. 按需加载补充空间
6. 跨空间一致性检查
7. 任务功能贞验 -> Z_T

步骤3和4可并行执行, 互不依赖。

## 跨空间一致性检查

比较两条路线:
```
路线A: 完整元信息 -> 压缩元信息(M_T) -> 从M_T提取互(H'_T)
路线B: 完整互信息 -> 压缩互信息(H_T)
```
若 |H'_T - H_T| > ε_T: 说明元压缩删除了生成关系所需的对象特征, 或互压缩删除了无法由元信息恢复的关系特征 -> 恢复被删特征。

## 路径残差

```
A --- C (直接互)
A --- B --- C (复合互)
```
两者的差异 = 路径残差。路径残差≠0说明直接关系和经由中介的关系不完全等价。
路径残差是互信息空间的特殊特征, 不能被压缩删除, 即使快速任务也必须保留。

## 信号编码

- s_M / s_H: 连续信号分数 [0,1], 用于边界判定、置信度计算和重算
- q_M / q_H: 离散路由码, 用于快速路由和查表
- 卦码仅用于一级寻址, 不用于质量判断/真实性判断/深度判断

## 快速任务约束

快速通道只能:
- 降低轴数量(最低各1轴)
- 降低关系展开深度(只保留直接互)
- 降低补充空间数量(全部optional)
- 使用粗粒度卦码

不能:
- 把互信息降为零
- 关闭元信息提取
- 删除路径残差(如果存在)

## 子skill独立性

元归一化和互归一化是独立子skill:
- 不依赖彼此(可并行)
- 不依赖conscious/unconscious/deep-conscious
- 不依赖缓存波动力学
- 可独立运行, 只要输入 B_T + 原始材料
- 输出格式: YAML + JSON兼容
- 不依赖本地绝对路径, 不依赖Hermes特定API
