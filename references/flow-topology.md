# 天地人拓扑

> 天↔地↔人拓扑。地位于天与人之间, 管理信息的流与止。

---

## 冻结定义

1. 地位于天与人之间
2. 地管理信息的流与止
3. 地本身不携带固有方向
4. 方向只存在于某一次具体流通事件中
5. 不默认存在绕过地的天->人或人->天直连
6. 如业务上出现天与人的直接作用, 必须将其展开为经由地的读取、环境、媒介或转换过程
7. 不得将地定义为"天和人的输出结果"
8. 不得把"天×人->地"作为总项目基础本体

## 拓扑结构

```
藏层(三才):
  天才(规律) ↔ 地才(环境) ↔ 人才(实践)

归层(三题):
  天题(本来样貌) ↔ 地题(读取方式) ↔ 人题(读取记录)
```

地才和地题都居中, 但职责不同:
- 地才(藏): 环境承载, 管理信息的保存边界
- 地题(归): 读取方式, 管理信息的流通路径

## 旧本体处理

| 旧定义 | 处理 |
|--------|------|
| 天×人->地 | 仅保留于版本来源记录。不得进入规范层 |
| 六个耦合界面(天×地/地×人/天×人等) | 重新解释为FlowEvent |
| 地=耦合结果 | 禁止。地居中, 不是输出 |

## 与FlowEvent的关系

拓扑定义结构, FlowEvent定义运行:

- 拓扑: 天↔地↔人(无方向, 只有位置)
- FlowEvent: 天->地->人(有方向, 在具体事件中)

同一个地可以在不同事件中承担不同方向的流止管理。
