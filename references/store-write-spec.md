# 藏写入规范

> 藏协议的写入规则。所有藏节点必须遵守。

---

## 1. ID 规则

```
store_id 格式: store_{layer}_{timestamp}_{seq}
  layer: tian | di | ren
  timestamp: YYYYMMDD
  seq: 3位序号
示例: store_tian_20260727_001
```

## 2. 路径规则

```
reference/store/{store_id}.yaml
```

使用相对路径。禁止:
- /mnt/c/Users/...
- D:/...
- C:/...

## 3. 证据类型

| 类型 | 说明 |
|------|------|
| excavation | 考古发掘 |
| text | 文献记载 |
| experiment | 实验数据 |
| user_input | 用户输入 |
| observation | 观察记录 |
| literature | 学术文献 |

## 4. 置信度

```
0.00-0.30: 弱信号(单源/未验证)
0.30-0.60: 中等信号(单源已验证/多源未交叉)
0.60-0.85: 强信号(多源交叉验证)
0.85-1.00: 确定性信号(金标准验证)
```

## 5. 版本规则

- 藏节点不可直接修改
- 新信息产生新版本, 保留版本链
- 归结论进入藏时必须生成新节点(不覆盖)

## 6. 读取后验证

写入后必须:
1. 读回文件头部(frontmatter)
2. 读回文件尾部
3. 检查文件大小 > 0
4. 检查YAML合法性

## 7. 禁止

- 禁止在藏节点中写入抽象规律(抽象属于归)
- 禁止使用天×人->地作为基础本体
- 禁止使用六个耦合界面
- 禁止把地固定为地理物质条件
- 禁止将运行时节点写入 Skill 的只读 references/ (统一写入任务项目的 reference/)
- 禁止使用绝对路径
