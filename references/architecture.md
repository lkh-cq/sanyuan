## 一、冻结本体

### 三才（藏）

| 位置 | 固定含义 |
| --- | --- |
| 天才 | 规律 |
| 地才 | 环境 |
| 人才 | 实践 |

### 三题（归）

| 位置 | 固定含义 |
| --- | --- |
| 天题 | 信息的本来样貌 |
| 地题 | 读取方式 |
| 人题 | 读取记录 |

藏是信息储存方式，保存具体内容；归是信息流通方式，形成抽象规律。三才与三题不得合并为同一分类层。

### 天地人拓扑

```text
天 ↔ 地 ↔ 人
```

地居天与人之间，管理信息的流与止，本身不携带固有方向。方向只属于某一次具体事件。“三元”只指这三个共享位置，不另设“天元、地元、人元”作为第三套分类。

### 互

互是独立关系观测空间，记录直接关系、复合关系、路径残差、流止、转换、反馈等关系状态。`FlowEvent` 是互空间中的事件子类型，不代表互的全部。互不是第四个本体实体，也不是信息论中的 mutual information。

### 核心控制约束

- `ρ + θ = 1`；ρ 管收束，θ 管切换，二者不是正确率与错误率。
- `n` 位聚焦只在离线或深睡阶段重建路由，调用阶段执行常数时间查表。
- 元信息空间 `M` 与互信息空间 `H` 独立编码、独立归一化，只在跨空间一致性阶段关联。

## 二、职责分离

| 权限 | 唯一职责 | 归属 | 不得越权 |
| --- | --- | --- | --- |
| 记录权 | 保存具体内容、来源与可观测关系 | 三才藏、互空间、三题归的读取记录 | 不评价好坏、真伪或是否继续 |
| 判断权 | 决定证据是否足够、路径是否采用、任务是否停止 | 意识总线与当前任务的验证标准 | 不静默改写原始记录 |
| 宽度权 | 决定当前加载多少相关节点 | ρ/θ 控制与下游注意力 | 藏归模块不得自行扩宽 |
| 粒度权 | 由来源层级、拓扑位置和任务边界共同导出 | 拓扑结构与 `B_T` | 不把粒度当作脱离任务的自由争论参数 |

“只记录联系，不代替下游判断”是职责原则，不代表取消证据边界。记录仍须标注来源、观测方式、争议与缺失。

## 三、分层架构

```text
来源层
├── 用户原话锚点与原始材料
└── 历史理论来源与版本迁移

预处理层
├── 任务边界
├── 三思而后行
├── 子任务拆分
└── 元/互独立归一化

观测与藏归层
├── 元信息空间 M：三才藏
├── 互信息空间 H：MutualNode / FlowEvent
├── 三题归：ReadNode
└── 耦合态：连接内容节点与关系节点的检索/写入事务

控制层
├── ρ 收束
├── θ 切换
├── n 位聚焦
└── 缓存波与压缩

交付层
├── 内部结果：保留节点、关系、路径、证据压力与缺口
└── 读者结果：转译为自然语言段落，默认不暴露内部编码
```

耦合态是存储事务封套，不是第四本体实体，也不取代 StoreNode、ReadNode 或 MutualNode。详见 [store-write-spec.md](store-write-spec.md)。

## 四、执行链

### 科研深度分析

```text
冻结输入 → 任务边界 → 独立研判 → 子任务拆分
→ M/H 独立编码与归一化 → 跨空间一致性 → 藏归与耦合态登记
→ n 位聚焦 → ρ 收束 → θ 边界检查 → 内部合成
→ 读者端自然语言转译 → 缓存波更新
```

### 快速信息筛选

```text
简化边界 → 最小 M/H 提取 → 简化研判 → ρ/θ 控制 → 结果转译
```

## 五、权威层级

1. 用户在当前任务中的最新明确表述；
2. 本文件的冻结本体与职责边界；
3. `project-manifest.yaml` 的版本、路径与生命周期登记；
4. 当前已激活模块；
5. 历史 Skill、Canvas、理论来源与归档候选；
6. Agent 的推断。

用户更正可以触发本体修订，但修订必须显式更新本文件、清单、迁移记录、Schema 与验收，不得只在一次回答中静默覆盖。

## 六、禁止行为

- 不得把三才与三题合并为单层分类。
- 不得另造“天元、地元、人元”作为第三套分类。
- 不得把天固定窄化为时空、把地固定窄化为地理物质、把人固定窄化为社会身份。
- 不得把地画成自带方向的箭头或定义为天与人的输出结果。
- 不得把互新增为第四本体实体、降格为 FlowEvent 或当作信息论互信息。
- 不得把耦合态与 MutualNode、FlowEvent 或独立事实等同。
- 不得把 ρ/θ 描述为正确率/错误率，不得伪造精确控制数值。
- 不得在调用时运行 Dijkstra 或同时激活多个冲突版本。
- 不得静默替换旧公式、删除旧定义或复活已归档冲突。
- 不得把只读 `references/` 当作任务运行时 `reference/`。
- 不得把内部编码、裸箭头、无注释简图或 YAML 账本直接当作读者端结果。

完整的 13 条反例免疫清单见 [framework-pitfalls.md](framework-pitfalls.md)。

## 七、来源与扩展边界

- [original-anchors.md](original-anchors.md) 保存用户原话与设计动机，不把历史窄化映射重新激活。
- [sanyuan-daobian-framework.md](sanyuan-daobian-framework.md) 浓缩八卷二十八章理论来源；其中历史、文字学、医学与天文命题按“作者理论来源”处理，不自动升级为外部事实。
- [yijing-coupling-matrix.md](yijing-coupling-matrix.md) 是实验性算子接口；没有观测数据或明确规则时，64×64 转移矩阵保持未知，不填伪权重。
- [reading-topology.md](reading-topology.md) 与 [reader-facing-analysis.md](reader-facing-analysis.md) 负责内部阅读结构和外部可读结果的分离。

新方案先进入迁移或实验层，只有通过证据、Schema、配方和行为测试后，才可提升生命周期状态。
