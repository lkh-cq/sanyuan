# 意识总线 V3 总项目

> 本项目以现有意识总线 V3 为唯一工程基线, 保留已成立的核心数学模块。
> 所有模块共享同一套本体、同一套ID、同一份manifest和可验证的机器链接。

---

## 一、冻结本体

### 三才(藏)
```
天才 = 规律
地才 = 环境
人才 = 实践
```

### 三题(归)
```
天题 = 信息的本来样貌
地题 = 读取方式
人题 = 读取记录
```

### 藏与归
```
藏 = 信息储存方式, 保存具体内容
归 = 信息流通方式, 形成抽象规律
```

### 天地人拓扑
```
天 ↔ 地 ↔ 人
```
地居天与人之间, 管理信息的流与止。地本身不携带固有方向。
“三元”只指天、地、人这三个共享位置，不另设“天元/地元/人元”分类。

### "互"
互 = 独立关系观测空间。FlowEvent ⊂ 互。
互记录直接互、复合互、路径残差、流止、转换、反馈等全部关系状态。
FlowEvent 只是互空间中记录天地人拓扑流止事件的一种子类型。

## 三、模块架构

```
核心层(数学模块, 独立)
├── ρ收束 (conscious-rho v3.0.0)
├── θ切换 (unconscious-theta v1.4.0)
├── n位聚焦 (deep-conscious v3.0.0)
└── 缓存波动力学 (cache-wave v1.0.0)

预处理层(门控, 依赖核心)
├── 任务边界编译 (v0.1.0, 在任何过滤之前执行)
├── 元归一化 (v0.1.0, 元信息空间独立归一化, 依赖任务边界)
├── 互归一化 (v0.1.0, 互信息空间独立归一化, 依赖任务边界)
├── 三思而后行 (v0.3.0, 依赖ρ和θ)
└── 子任务拆分 (v0.3.0)

观测空间层(独立编码, 独立归一化)
├── 元信息空间 M (三才藏为主编码器, 必选)
├── 互信息空间 H (references/hu-observation-space.md, FlowEvent⊂互, 必选)
└── 补充空间 (时间/证据/来源/不确定性, 按任务提升)

藏归层(可插拔认知分支)
├── 藏归调度器 (v0.3.0)
├── 藏: 三才(天才/地才/人才) -> StoreNode
├── 归: 三题(天题/地题/人题) -> ReadNode
└── 流止: FlowEvent(互的子类型) + 藏归循环

配方层(任务级组合)
├── 科研深度分析 (任务边界->元互双空间归一化->藏归->核心)
└── 快速信息筛选 (简化边界->最小元互提取->ρ/θ控制)

交付层(内部表示与读者产物分离)
├── 内部结果: 保留节点、关系、路径、证据压力与缺口
└── 读者端分析: 将内部关系转译为自然语言段落, 默认不暴露编码
```
