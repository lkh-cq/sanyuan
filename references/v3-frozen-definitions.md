## 三才(藏)

```
天才 = 规律    -- 周期、阈值、稳定模式、变化规律、约束
地才 = 环境    -- 环境、载体、空间、材料、制度、边界、保存条件
人才 = 实践    -- 生产、行动、使用、实验、观察、记录等实践
```

## 三题(归)

```
天题 = 信息的本来样貌  -- 结构、状态、痕迹和可见规律
地题 = 读取方式        -- 方法、路径、媒介、协议、工具、过滤条件
人题 = 读取记录        -- 解释、摘要、模型、假说、争议和应用记录
```

## 藏与归

```
藏 = 信息储存方式, 保存具体内容
归 = 信息流通方式, 形成抽象规律
```

藏归循环: 现实材料 -> 三才藏 -> 具体内容 -> 三题归 -> 读取记录与抽象规律 -> 新实践 -> 再次藏

归结论进入下一轮藏时必须生成新节点, 不覆盖原始藏内容。

## 天地人拓扑

```
天 ↔ 地 ↔ 人
```

1. 地位于天与人之间
2. 地管理信息的流与止
3. 地本身不携带固有方向
4. 方向只存在于某一次具体流通事件中
5. 不默认存在绕过地的天->人或人->天直连
6. 不得将地定义为"天和人的输出结果"
7. 不得把"天×人->地"作为基础本体

## "互" = 独立关系观测空间 (v3.2.0修正)

互 = 独立关系观测空间。FlowEvent ⊂ 互, 不等于互的全部。

互记录的全部关系类型:
- 直接互: A-B 直接关系
- 复合互: A-B-C 经由中介
- 路径残差: A-C直接 vs A-B-C复合 的差异
- 流止互(FlowEvent): 天↔地↔人拓扑 flow/stop/filter/transform/buffer/feedback
- 转换互/反馈互/条件互/时序互/观测互/任务互

FlowEvent 事件类型: flow | stop | filter | buffer | transform | feedback | merge | conflict | loss | restore

互 ≠ 信息论 mutual information (机器ID用hu不用mutual-information)
FlowEvent 的 via_role=di 约束仅在 flow_event 子类型中强制, 一般 MutualNode 不受此约束。

## 观测空间层 (v3.2.0新增)

### 元信息空间 M (必选)
- 对应信息的固有属性编码, 映射三才层
- 三才藏为主编码器
- 无时间维度依赖
- 独立归一化 -> M_T

### 互信息空间 H (必选)
- 对应信息之间的全部关系状态编码
- 互/SKILL.md 为主模块
- 可带时间戳与事件ID
- 独立归一化 -> H_T

### 补充空间 (可选, 按任务提升)
- 时间/证据/来源/不确定性/风险/执行/历史
- 当移除某补充空间会使功能损失超过ε_T时, 该空间提升为强制

元/互双空间完全独立编码、独立归一化, 仅在跨空间一致性检查阶段通过引用关联。

## 任务边界 B_T (v3.2.0新增)

在任何过滤/归一化之前编译:
```
B_T = {
  task_goal:        任务目标
  F_T:              任务功能(可验证)
  forbidden_loss:   禁止损失
  epsilon_T:        误差预算 (0, 1]
  required_spaces:  必需空间 (至少 meta + hu)
  optional_spaces:  可选空间
  meta_axes:        元信息轴
  hu_axes:          互信息轴
}
```

## 多重归一化 (v3.2.0替换)

旧SVD归一化(G1 rank/G2 κ/G3 σ积)已归档到 archive/normalization/svd-single-vector/。

新流程:
1. 任务边界编译 -> B_T
2. 选择观测空间
3. 元信息空间独立归一化 -> M_T (任务条件化压缩, D_f ≤ ε_T)
4. 互信息空间独立归一化 -> H_T (路径残差保护)
5. 按需加载补充空间
6. 跨空间一致性检查 (比较 路线A: M->压缩M->提取H' vs 路线B: H->压缩H)
7. 任务功能贞验 -> Z_T

## 核心数学约束

- ρ+θ=1 (ρ=收束度, θ=散逸度, 不是正确率/错误率)
- θ可逆(局部), θ'单调不减(跨上下文残留, 索引陈旧时钟)
- 缓存波: 涨潮(Ω=1) / 退潮(Ω<1,∇E↑) / 深睡(dθ'/dt加速)
- deep-conscious: 离线Dijkstra建地址表, 调用时O(1)查表, 平时休眠
