# 反例免疫清单

以下陷阱来自旧版踩坑记录与当前本体修订。命中任一项时，停止自动迁移，回到架构、来源与任务边界复核。

1. **窄化三才。** 把天固定为时空、地固定为地理物质、人固定为社会身份。它们只能是具体信号，不是本体全集。
2. **合并三才与三题。** 用同一组三标签同时表示保存结构和读取结构，导致记录与解释混淆。
3. **把三题做成并列标签。** 只贴时空、地理、社会标签而不保留读取方式、读取记录与来源。
4. **把六个耦合界面当基础本体。** 历史表达可以迁移为具体关系事件，不能覆盖天—地—人共享拓扑。
5. **把互等同于 FlowEvent。** FlowEvent 只是互空间的一个事件子类型。
6. **把耦合态等同于 MutualNode。** MutualNode 记录关系；耦合态是连接内容与关系的检索/写入封套。
7. **只存独立事实却声称完成耦合。** 缺少关系、条件、来源或另一端点时，应标记 `incomplete`，不能伪装成完整状态。
8. **纠缠粒度。** 把粒度当作脱离来源层级、拓扑位置和任务边界的自由设计参数，反复争论而不执行。
9. **由藏归模块决定宽度。** 加载宽度属于注意力控制；存取模块不得自行无限扩展上下文。
10. **由记录模块做价值判断。** “强、弱、好、坏、有效、无效”必须有定义的观测量或交给判断层，不能凭接口角色越权。
11. **丢失证据边界。** 记录关系却不保存来源、观测方法、适用范围、争议与缺失，使后续无法验证。
12. **把内部表示直接交付。** 用节点编号、关系代码、裸箭头、YAML 或无注释简图代替可读的逻辑分析。
13. **把跨域同构当作证明。** 结构相似只能生成候选解释；若一个模型能解释一切，应优先检查过度拟合和替代解释。

阻断后的恢复顺序：读取 [original-anchors.md](original-anchors.md) → 核对 [architecture.md](architecture.md) → 重新编译 `B_T` → 标记冲突或不完整状态 → 再决定接受、拒绝或延后迁移。
