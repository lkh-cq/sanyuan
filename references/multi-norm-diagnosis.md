# 多重归一化过滤 — v1.0 问题诊断与 v2.0 方向

> 编制: 2026-07-27 | 来源: 四重约束理论框架 + 易术算子校正
> 定位: 替代旧 `多重归一化过滤_SKILL.md` 的设计基础

---

## v1.0 六大问题（逐项确认）

| # | 问题 | 判断 | 说明 |
|---|------|------|------|
| 1 | G1/G2/G3 无 B_T 输入 | 完全成立 | 没有任务边界就无法定义相关特征和允许损失 |
| 2 | rank≥2 作为质量指标 | 完全成立 | rank 描述结构维数 ≠ 任务价值 |
| 3 | 三维向量 SVD 无意义 | 有条件成立 | (1×3) 向量非零 rank 恒为 1；对角化后 SVD 无新信息 |
| 4 | 被归一化对象错误 | 成立 | 三维分布形状是文档类型特征，不是质量判据 |
| 5 | 应使用文档集合矩阵 | 基本成立 | 但 (D×3) SVD 仍优化全局方差，不保证任务功能保持 |
| 6 | 无 F_T, D_f, ε_f | 完全成立 | 无法证明被删内容对任务无功能贡献 |

## 根因

**SVD 保留高方差方向，但低方差方向可能恰好是当前任务的关键特征。**

SVD 适合做：语料结构诊断、冗余检测、候选低维空间构建。
SVD 不适合做：文档质量裁判、最终生杀门控。

## v2.0 方向：两坐标系 + 四重约束

### 坐标系分离

```
C_info (信息点空间):  八卦 × 三爻 → 信号存在性检测
C_coupling (耦合空间): 64卦转移矩阵 → 耦合事件分析
```

### 两层架构

```
第一层: 全局规范化（任务无关，不可删信息）
  · 格式噪声去除 · 三才编码(K维特征) · 来源绑定 · 证据等级标记
  → 永久藏库，不因任务裁剪

第二层: 任务条件归一化（B_T 输入）
  · w_T ⊤ x_i → 任务相关性得分
  · x_{ij} ≥ m_{T,j} → 必需维度最低阈值
  · 选择满足覆盖的最小子集 S_T
  · F_T 功能验证 → D_f ≤ ε_T
  → 产物: Z_T（任务视图，非唯一表示）
```

### 四重约束（替代旧 G1/G2/G3）

```
特征覆盖约束  → 必需特征是否缺失
结构保持约束  → 因果方向/条件关系是否被压平
语义损失约束  → 非任务语义可丢，任务语义不可丢
任务功能约束  → F_T(Z) ≈ F_T(X)，可验证
```

### 文档不删除，只标记

```yaml
task_applicability:
  task_id: T-001
  status: inactive
  reason: "不覆盖任务必要特征"
  retained_signals: [地理条件, 材料来源]
  potentially_useful_for: [T-地理环境, T-资源分布]
```

六种状态: active | supporting | redundant | insufficient | conflicting | out_of_boundary | unassessed

## 与易术算子的对接

G1(旧 rank≥2) → 卦映射: 文档 → 天/人/地三爻信号检测 → 八卦标签
G2(旧 κ>1.5) → B_T 目标卦集选择: 按任务确定需要哪些卦
G3(旧 σ积)  → 汉明距离排序: 距目标卦越近越优先还原
元亨利贞    → 闭环迭代: 初始化→扫描→筛选→纠错→调整

SVD 降为诊断工具: 全局语料结构分析 + 冗余检测。不参与门控。
