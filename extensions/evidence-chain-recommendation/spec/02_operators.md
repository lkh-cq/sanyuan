# 02 · 算子 O1–O7

> 每个算子给：**定义 / 方程 / 失效形态 / 在实现里的位置**。失效形态一栏是硬要求——没有它，算子只是伪代码。
> 版本 v1.0 · 2026-11-12 · 实现 `scripts/ecr_plan.py`

## O0 · 输入闸门（在 O1 之前）

1. 命题 `x` 原文冻结，分解 `x₁..x_k` 必须存在；否则**不启动**（无分解则 π 无定义）。
2. 每条 a_i 跑 O7 十不变量；`blocked` 集合不参与后续任何计算。

## O1 · 覆盖分层

```text
c_j = |{ i : x_j ∈ π_i  且  stance_i,j ∈ {support, refute, partial} }|
C = { x_j : c_j ≥ 2 }     共识层
U = { x_j : c_j = 1 }     独占层
G = { x_j : c_j = 0 }     缺口   → 必须进输出
```

- **失效形态**：
  - 缺口静默消失 → 命题不可证的位置被当成"无需证"（本次实例 x6 即为真实缺口）
  - 用"高权威单一来源"冒充共识 → 那只是 c=1 的独占层
  - 把 `undecidable` 计入 c → 低检验力证据把缺口填成共识（v1.0 已修）
- **实现**：`coverage()`

## O2 · 预算分池

```text
B_L = Σ_{locked 子问题} max(L0 of 覆盖它的证据)      # 逐证据去重
B_U = ⌈λ · B⌉,  λ = 0.30
B_C = B − B_L − B_U
若 B_C < 0 → status = infeasible（仍出计划，显式报不可行）
```

- **为什么分池**：`密度`（共识层多铺证据）与`完善`（独占层逐字核对）是两个目标，同池竞价会互相挤出 → 独占层永远抢不过便宜的共识层。
- **失效形态**：λ 设 0 → 该层永不入选，"防保守"条款形同虚设；B_L 按单条而非按证据去重 → 同一文件重复计费。
- **实现**：`pools()`

## O3 · 边际价值（含佐证项与检验力）

```text
ΔD_i = Σ_{x_j 新覆盖} w_j  +  Σ_{x_j 已覆盖且 stance 一致、该子问题佐证数 ≤ 2} 0.25
       w_j = 2.0 (critical) | 1.0 (否则)
bytes(i, mode) = max{ volume_i, mode[x_j] : x_j 被本候选使用 }
v(i, mode) = ΔD_i / bytes(i, mode)
```

- **两条硬规则**：
  1. **排序只看 v**，不看权威、被引、篇幅、trust_tier。
  2. **检验力前置**：`power.expected_min_cell < 5` → stance 降 `undecidable`，**不计入 c 与 ΔD**，直接进 gaps。
- **为什么加佐证项**：只算"新覆盖"时，每个子问题只会进一条证据——那是**单点依赖**，不是共识。佐证值上限 2 条，防无限堆砌。
- **失效形态**：
  - 无检验力闸 → "0 次发生"被当成"不存在"（本会话 `1→2=0/10`，期望 1.04、z=−1.21，ns）
  - 佐证无上限 → 大文件凭体积优势挤掉独占层
- **实现**：`build_chain()` 的候选打分

## O4 · 停机准则

```text
当 max_i v(i,·) = 0（既无新覆盖、也无可用佐证）→ 停
余项全部进 dropped + recovery_refs
```

- **为什么必须有**：「最小」若无停机条件，永远能再添一条显得更完善。
- **失效形态**：无停机 → 计划随候选池大小线性膨胀，最终等于"全注入"
- **实现**：`build_chain()` 的 `stop_reason`

## O5 · 三级降维与分辨率升级

```text
装配档位: locked → L0 ; 独占层 → L1 ; 共识层 → L2
升级: 仅对**已进链**证据，L2 → L1，用 B_C 余量（按链序优先）
```

- **失效形态（v1.0 修过一次）**：把"未进链的证据"也计入升级 → 预算虚耗（首版实测 45,165 B，修正后 35,195 B）。升级是**提高已选证据的分辨率**，不是**再选一批证据**。
- **实现**：`build_chain()` 尾段

## O6 · 门位标注与均衡

```text
每条 a_i 必填 gate ∈ {0..5}
输出 coverage.by_gate = { gate: 链内条数 }
告警: 若链内 gate=3 全有而 gate=0/2 为空 → 报 "现象孤证"，建议补 0/2 门证据
```

- **依据**：耻辱柱 32 条事故中，gate 0 占 28.1%、gate 2 占 25.0%，gate 3 仅 9.4%。**错误产生在 0/2，代价在 3 兑现**。
- **失效形态**：只按体积/覆盖率选证据 → 链里全是"现象层"结论，一查判据就塌
- **实现**：`plan()` 里 `by_gate` 统计（v1.0 目前只统计+输出，不强制阻断；强制阻断留待 v1.1 由用户裁决阈值）

## O7 · 十不变量闸门

见 `01_terms.md` §1.6。实现要点：

| 检查 | 触发条件 | 结果 |
|---|---|---|
| B | `provenance.verified != true` | 拒载 |
| B | 运行时 `bytes != 声明值` 或文件不存在 | 记 failed（B），拒载 |
| I | `claim_type` 不在白名单 | 拒载 |
| I | `claim_type == relayed` 且无出处 | 记 failed（B+I），拒载 |

- **失效形态**：闸门只写文档不进代码 → 会被"改名"绕过（I 的由来）；检查点挂在交付而非落笔 → 违规发生在中间产物（J 的由来）。

## O8 · 基线统计算子（已实现；不是"人工复核"）

若 ECR 要报告"某类证据被高估/低估"（如"文献证据占比过高"），必须：

1. 用**准独立基线**扣度数边际：`E_ij = n_i·n_j / N`，逐格调整残差；
2. 用**配置模型**（随机配对出/入桩）做保度检验——**不得**用保边集的随机化，那会让统计量恒定（本会话实测 p 恒为 1.0000 的退化病例）；
3. 逐格期望频数 ≤ 3.25 时**禁止**报告逐格 p（正态近似失效），只报方向与幅度。

> 理由：本会话曾用"只固定词表"的置换检验得出"回溯低于随机"（p=0.0052），扣度数边际后该结论**撤回**；唯一存活的是"门内自持"（22 vs 8.75，p=0.0001）。**ECR 不能重犯它用来防的错。**

### 实现（`scripts/ecr_o8.py`，每次 `plan()` 必跑）

| 输出字段 | 内容 | 方程 |
|---|---|---|
| `margins` | 证据行边际 `n_i`、子问题列边际 `n_j`、`N` | — |
| `cells[]` | 每个实有格的准独立期望与调整残差 | `E_ij = n_i·n_j/N`；`z_ij = (1−E_ij)/√(E_ij(1−n_i/N)(1−n_j/N))` |
| `cell_level` | 逐格推断是否可用（三态）+ `min/max_expected` | 见下 |
| `null_model` | C-score 实测值 + 保度零分布 | `C = Σ_{j<k}(R_j−S_jk)(R_k−S_jk) / #pairs`；棋盘格交换保双边边际 |
| `readout[]` | 平铺的数值现象（含 `p_low` / `p_high`） | — |

**三态判定的依据（这是本算子唯一的"判断"，可机械复核）**：

- `allowed`：`min E ≥ 5`；
- `forbidden`：`matrix_scale="counts"` 且 `min E < 5`（Cochran 规则，逐格 p 禁报）；
- `not_applicable_binary`：`matrix_scale="binary"`（默认）且 `min E < 5`。

> **为什么 binary 尺度要单列一态**：0/1 关联矩阵的期望格受边际约束——平衡结构下 `E ≡ 1`，永远达不到 5。这不是"数据不够"，而是**逐格推断在该尺度上无定义**。把这两件事混成一个 `forbidden`，会让使用者以为"再补几篇文献就能算"，从而去追一个不存在的量。`t4` 用 hub 结构（单格 `max E=5.26`）钉死这一点：即使某格 E 冲到 5 以上，只要还有小格，0/1 尺度仍判无定义。

零分布固定 `seed=20261112`，重复次数由 `--null-reps` 控制（默认 1000）；同输入两次运行逐字节一致（`t4` 断言 + §5.3 回归）。

## O9 · 收敛度算子（单调目标函数）

**这不是"判对错"，而是"判有没有更靠近"**。磨合期允许不命中；不允许的是「掷了一轮，离错误目标没有更远」这种无法验证的进展。

### 定义

对每一轮的注入计划，读出**错误向量** `e`，再算**离错误目标的总距离**：

```
D = Σ_i w_i · e_i          （越小越好）
D_rel = D / D_max(k)       （k = 子问题数，用于跨任务规模比较）
```

| 分量 `e_i` | 含义 | 权重 `w_i` | 读自哪个字段 |
|---|---|---:|---|
| `gap` | 子问题 `c=0`（不可判） | **3.0** | `gaps` |
| `single_source` | 子问题 `c=1`（单点依赖） | **2.0** | `coverage.c` |
| `blocked` | 被闸门拒载的证据数 | 1.5 | `blocked` |
| `unverified` | 出处未核（不存在/bytes 不符） | 1.0 | `provenance` |
| `gate_missing` | 链内 gate 0/2/3 缺几个 | 1.0 | `coverage.by_gate` |
| `no_corroboration` | 链内每子问题只有 1 条证据 | 0.5 | `chain[].subquestions` |
| `scale_mismatch` | 逐格尺度不可判（binary） | 0.5 | `power.cell_level_status` |
| `budget_underuse` | 预算利用率 < 50% | 0.5 | `budget` |

**权重是声明，不是调参**：缺口比单源依赖贵（前者不可判，后者可补）；拒载次之（候选合规性）；其余两项 0.5 是"可优化项"而非错误。

### 单调性（这就是"阳性依赖函数")

- 给出 `--prev-plan` 时，输出 `delta`、`components_delta`、`monotone = (ΔD ≤ 0)`、`verdict ∈ {improved, flat, regressed}`；
- `regressed` 必须同时给出 `regressed_by`（哪几个分量上升）——**不允许只说"退步了"**；
- 无 `prev` 时 `verdict="first_run"`，D 落账作为下一轮的基线；
- 反向对比必须判 `regressed`（`t5` 断言），同一计划自比必须判 `flat`（`t5` 断言）——**防止把"没变"记成"改进"**。

### 为什么用"离错误更远"而不是"离正确更近"

正向正确率需要一个完备的正确集（本制度没有，也不该伪造）；错误侧是**可枚举**的：缺口、单源、拒载、未核、门位缺失、冗余不足——每一项都能回指到 plan 里的一个字段。所以 `D` 是**阳性依赖**的：修好哪一项，D 就掉哪一块，且掉多少由权重与计数直接给出，无需主观评分。

### 失效形态

| 失效 | 表现 | 防御 |
|---|---|---|
| 把 D 当评分用 | 拿 D 跨不同命题比较 | 只用 `D_rel` 且仅在同 `k` 内比较；跨任务比 `components_delta` 不比率 |
| 刷 D 而不改实质 | 为降 `budget_underuse` 硬塞证据 | 塞证据会推高 `blocked`/`unverified`，且 `ΔD>0` 即 `regressed` |
| 只报 Δ 不报分量 | "这轮更好了" | schema 要求 `components_delta` 必填 |
| 基线漂移 | 换了命题后仍与旧 D 比 | 跨命题比 D 违反红线 19；`--prev-plan` 的同命题由调用方保证 |
