# 01 · 术语与符号

> 本文件只定义符号与取值域，不含算法（算法见 `02_operators.md`）。
> 版本 v1.0 · 2026-11-12

## 1.1 命题侧

| 符号 | 定义 | 约束 |
|---|---|---|
| `x` | 核心命题，**原文保留** | 不得为追求可算而改写 |
| `x₁..x_k` | 命题分解出的**可判定子问题** | 无分解则 π 无定义，ECR 不得启动 |
| `type(x_j)` | `exist` 检出与否 / `direction` 方向 / `magnitude` 数值倍数 / `mechanism` 机制链 | `magnitude` 通常强制 locked |
| `resolution(x_j)` | `locked`（必须保原文分辨率）/ `free` | locked 子问题独占 B_L 池 |
| `critical(x_j)` | 布尔 | 真 → 权重 2.0，否则 1.0 |

## 1.2 证据侧

| 符号 | 定义 | 约束 |
|---|---|---|
| `a_i` | 证据单元，可独立加载 | 必须带 `path` + `bytes`；sha256 运行时重算 |
| `π_i(x)` | a_i 在 x 需求面上的可判定投影 ⊆ {x₁..x_k} | 落成 `projections[]` |
| `stance` | `support` / `refute` / `partial` / `neutral` / `undecidable` | 前三个算"可判定"，参与 c 与 ΔD |
| `volume{L0,L1,L2}` | 同一证据的三级体积（字节） | L0 = 原文原字节；L1/L2 为降维后的上限 |
| `trust_tier` | `disk` / `literature` / `inference` | 只作标注，**不参与排序**（排序看 v，不看权威） |
| `gate` | 观测位置，取值 0–5（见 1.3） | **必填** |
| `claim_type` | `measured` / `relayed` / `inferred` | **必填，三选一**；relayed 需 `upstream_of` + `provenance` |
| `power` | `{n, expected_min_cell}` | `expected_min_cell < 5` → 降为 undecidable |
| `proxy_of` | 若该证据是某本体的代理，写本体标识 | 无 `proxy_domain_verified` 则不得进链（A） |

## 1.3 六门（观测位置）—— O6

| gate | 名称 | 判据 | 耻辱柱 32 条中的事故数 |
|---|---|---|---|
| 0 | 设施 | 原理要求的观测量能不能测到 | 9（28.1%） |
| 1 | 承载物 | 测的是不是原理说的那个东西 | 5（15.6%） |
| 2 | 方法 | 判据有无来源、是否在原理定义域内 | 8（25.0%） |
| 3 | 现象 | 呈现是否与原理预测一致（理论←结果的耦合界面） | 3（9.4%） |
| 4 | 元层 | 三者皆合法仍不符 → 对象/观测者本身 | 4（12.5%） |
| 5 | 冻结 | 交付/归档/复现断言（可撤销） | 3（9.4%） |

> 事故数来自 `_SHAME_DISTILL_v1.md` §3（编码表 `coding_shame_pillar_20261111.csv`，32 条）。
> **用法**：注入计划若只含 gate=3 的证据，等于把"现象对"当作"整条链对"。0/2 门的证据是现象的**支撑面**，缺失即不可判定。
> 用户的判据几乎总在 gate=3 收口，而错误产生在 0/2 门 —— 这是门位均衡的理由，不是修辞。

## 1.4 三档降维

| 档 | 内容 | 使用条件 |
|---|---|---|
| **L0** | 原文/原始数据（原字节） | `resolution=locked` 强制；或独占层要求逐字核对时 |
| **L1** | 断言级：只留与 π_i 对应的断言 + 数值 + 出处 | 独占层默认；共识层升级后 |
| **L2** | 方向标签：support/refute/neutral + 一句理由 | 共识层默认 |

> 规则：只有被 x 需要的子问题才允许降维；**未被任何子问题需要的证据，任何档位都不注入**（进 `dropped`）。

## 1.5 预算

| 符号 | 定义 |
|---|---|
| `B` | 注入预算硬上限（字节） |
| `λ` | 独占层预算下限比例，默认 **0.30**（防制度自证保守） |
| `B_L` | 锁定池 = Σ(覆盖 locked 子问题的证据的 L0) |
| `B_U` | 完善池 = ⌈λ·B⌉（独占层证据，L1） |
| `B_C` | 密度池 = B − B_L − B_U（共识层：佐证 + 分辨率升级） |
| 可行性 | `B_C < 0` → `status=infeasible`，仍输出计划并显式报不可行 |

## 1.6 十不变量（O7 闸门）→ 字段映射

| # | 不变量 | 落地字段 | 不过的处理 |
|---|---|---|---|
| A | 表层替代结构 | `proxy_of` + `proxy_domain_verified` | 记 failed，不进链 |
| B | 断言先于证据 | `provenance.verified` / 运行时 `bytes`+`sha256` | **拒载** |
| C | 不同框 | `domain.scope` + `domain.frozen_scale` | 记 failed（跨域不可比） |
| D | 入口错 | （流程层，非证据层） | 由 `moments.T1` 承载 |
| E | 静默失效 | `usable` + 显式 NA | **拒载** |
| F | 越权 | `authorization.in_scope` | 只列不注入 |
| G | 继承未核 | `upstream_of` + `claim_type=relayed` | 记 failed，降为 relayed |
| H | 降维 | `resolution{locked,free}` | 锁 L0 或降档 |
| **I** | **命名逃逸** | `claim_type` 三选一 | **拒载**（无法区分实测/转述即不可信） |
| **J** | **闸门位置错** | `moments{T1..T5}` 必填 | plan 缺 moments = 未完成 |

## 1.7 五个落笔时刻（T1–T5）

| 时刻 | 必检不变量 | 一句话判据 |
|---|---|---|
| T1 写任何数字前 | B, D | 这次查了吗？查的是最近版本吗 |
| T2 写「实测/已验证/已核」前 | B, **I** | 这个动词是不是换了名字的"没查" |
| T3 写「覆盖度/审核完成」前 | A, E | 用的是不是代理？探针只能做回归验收 |
| T4 写结论/主因/权重前 | H, A, E | 门槛接到检验了吗？基线去了吗？是否压成一维 |
| T5 写归档/交付/补录前 | B, F, **J** | 零出处落笔了吗？在授权面内吗？闸门在落笔处还是交付处 |
